# 单模块审阅

本文件是候选稿形成后的审阅提示。按当前阶段的授权与课程方法执行，审阅记录归课程角色目录。

## 1. 保存稿件后重新读取

每章初稿或完整修订稿保存到代理工作区后，实际打开并通读本文件，再按下列顺序读取磁盘上的依据。每章单独执行，批次启动时的阅读不能代替本轮重读。

1. 读本单元适用的 O 来源策略、A 模块映射和边界、完整 B 编写共识及其适用范围。按声明的生效任务选择已确认版本。读 B 登记的内部校准样稿与必要资源；样稿身份异常按[基准治理](../stages/04-audit-and-update.md#反馈与基准治理)核对。
2. 依 O、A 重新打开本章映射的允许原材料，重读本章所用课件、教材、训练、样卷或数据的对应页段和任务，覆盖本章范围及必要上下文。找出来源实际要求的对象、关键关系、输入与输出、图形和边界。材料目录、旧摘要、覆盖表及此前的阅读记录仅供定位。若扫描页、图或表的意义取决于版面，查看该页原貌。关键依据不可读时记录具体缺口，暂停相应通过判断。
3. 打开已保存的当前稿和实际附件，通读学习正文并执行下列检查。首次 B 使用 O、A、课程 B-v0 和本轮明确要求，正文先脱离编写批注审读，再核对说明。旧章只读或局部审修以授权范围为限，读对应材料和稿件，记录该范围内的判断；独立的 O/A/B 重启沿用其阶段流程。

## 2. 核对来源、边界与内容依据

对照 O 的来源用途、使用程度和课程情境，以及 A 的材料映射、模块边界、顺序和接口。依据覆盖核对与原始材料检查遗漏、详略和归属。对清单、自检、变式或提醒，核对来源中它解决的任务在本节是否仍存在，再决定保留、移位或删并。事实、公式条件和训练要求回到材料核实。

## 3. 联合对照 B 共识与已确认样稿

按整课、知识类型和单章范围识别适用的 B 条款。逐节对照时同时寻找违反该条款的位置，尤其留意首次参与推理的概念、公式后的功能转换和段末提醒。若一处合格而另一处漏做，判为部分落实，定位差异并复查本章同类位置。适用项区分已落实、部分落实、未落实和未验证；不适用项注明范围。相关条款可合并记录。

`B 的适用要求 → 样稿中的实现位置与作用 → 本章对应位置与实现方式 → 是否达到所要求的理解、区分或定位效果`

样稿体现用户已接受的实现形式，用于辨认抽象要求在正文中的效果，不要求复制目录、标题层数、段落数量、详略比例或图形密度。当前有效 B 已调整历史写法时，以当前 B 为准；样稿未覆盖的知识形态依据 B 与本章材料判断，简记适配理由，不冒称已由样稿验证。下列审读落实此联合对照，不另做一遍重复检查。

## 4. 检查完整标题树与各节解释功能

先完整读取标题树，检查知识主线、命名、父子关系和编号，再逐节检查正文是否与标题概括的共同内容或解释功能相符。

对包含多段文字、公式或图例的小节，检查是否混合了需要独立理解、区分或查阅的任务；需要显露结构时按呈现规则采用适当小标题或局部标签。同一机制或连续推导保留必要连续性，一个标题下多段文字本身不是缺陷。

结合样稿的对应做法，定位“内容齐全但解释功能难以区分或查找”的退化；不能仅凭标题数量、最大层级、段落长度或编号正确判定通过，也不能只抽查开头或某个小节代替逐节审读。

## 5. 连续审读表达并检验首次调用

按课程约定的读者前置从头顺读学习正文。首次遇到表格比较、公式、图或关键结论时，只用此前已读内容解释对象、依据和这一句的作用；符号名称对应仍可能缺少概念含义。定位首次需要回翻后文、猜测指代或自行补推理的位置。同步检查符号、强调及重复解释。按[辨析与提醒的使用条件](presentation-rules.md#辨析与提醒的使用条件)审读限定语，包括表后、式后和段末的连续提醒。

沿本章代表性任务从实际给定信息走到所要求的最终形式。逐步在正文定位所需概念、关系和操作，实际演算或解释。任务要求可反复查阅的关系式时，检查正文是否给出目标形式及其条件；另行复算得到正确数值只支持数值结论。重生成按原材料、适用 B 和已知阅读障碍回归必要学习功能，旧稿的读取范围服从用户授权。

从知识单元逐一判断读者是否需要建图、读图或辨认点与关系，包括当前没有图片的单元。缺失的必要图补齐后，连同已有图按下节逐幅验收。对发现的阅读缺口补足最短必要解释，修正后从受影响位置重新走一遍。

## 6. 检查接口、图文和技术结果

按 A 核对已完成相邻章节中的前置、符号、引用、重复和内容主归属，尚未生成的后章读材料映射。其他学习阶段仅核对必要只读接口。按[图形验收](presentation-rules.md#图形验收)在最终阅读尺寸逐幅查看，定量图另用模块适配器核对数据、单位及图中关键值与正文的对应。用统一 [markdown_qa.py](../../scripts/markdown_qa.py) 检查 Markdown 和资源引用；局部工具只补充检查。分别注明已核对的任务覆盖、图形语义、实际显示、数值及文件格式，以及无法验证的环境。

## 7. 修正并复核受影响范围

将问题修入候选稿，重新读取修改处并核对受影响的上下文、标题树、公式、图文和接口。局部措辞调整局部复核；结构、推导或内容归属变化扩大到受影响范围，避免润色改变条件与结论。依据变化或执行中断时重新核对适用版本和未完成步骤。

同类问题回查本章其余适用位置。重写后按原材料与有效 B 同时核对曾有障碍的功能和已经有效的解释，保留正确推理、必要边界及可查阅的关系式。只读任务给出定位和修复建议。

## 审阅记录与通过条件

沿用现有内部单元记录，不新建另一套课程状态。记录所用 O/A/B 版本、样稿身份（首次 B 注明尚未校准）、本轮实际重读的材料页段或题号及被审阅稿件，并简记：`审阅方面｜依据与正文位置｜结论、修正复核或未验证项`。表格或短条目均可；正文位置可用小节编号/标题及公式、图号等定位，不复制长段正文。

- 分别给出内容完整性与组织合理性、B 执行程度、初学者顺读与首次使用的判断。B 记录适用要求、样稿作用及对应正文位置，部分落实或漏做的要求须在发布前修正复核；顺读记录实际检验的关系或任务、正文位置及遇到的障碍或通过依据。范围受限时标未验证。读者体验是代理依据正文的判断，用户实读反馈另记。
- 记录 O/A 与材料核对、实际调用验证、模块接口、图文及技术检查的范围与结果；区分用户反馈、自检发现及风险假设，无问题时不编造修复。
- 无已知关键缺陷、无关键待裁决项且必要检查完成后才发布；环境限制和未验证项如实列明，不能声称全部通过。正式路径复核完成后才能记录本单元完成。

仅保留简短结论、必要定位及修正复核结果；临时推演、覆盖清单和重复检查草稿不默认长期保存。详细记录只在代理目录，知识点正文不新增 QA 栏目，也不把完整 B 策略说明变成每章固定附件。
