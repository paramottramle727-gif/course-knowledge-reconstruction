# 基础内容组织共识、取舍与回归

## 基础组织与逐章决策

本文件是首次 B 的内容组织基础；表达方式由 [presentation-rules.md](presentation-rules.md) 定义。基础编写要求在首次 B 保存为课程 B-v0；此后当前明确指令与完整有效课程共识在其适用范围内执行，通用文件升级不静默替换课程方法，历史样稿只提供参照，不代替当前材料分析。

O 约定来源怎样使用，A 建立材料与模块的对应；本章具体需求在 B/生成/授权审修时深读相应课件与训练后确定。识别“知识对象、任务动作、条件或标准”及来源定位，区分材料明确要求与教学设计推断。频率、难度和题干形式按实际材料判断，不由课程名称、旧能力摘要或样稿布局推定；来源权重遵循有效 O。

在当前模块内形成“核心问题与前置 → 学习任务 → 关键理解障碍 → 内容与表达安排”。开头简述必要主线及联系，不增设固定目标清单。任务证据用于确定需要支持的能力，不能把练习顺序直接变成知识顺序。具体决定在单章闭环中验证，非跨章规则的处理保留在本章。

## 同类知识的共同框架

知识对象具有稳定共同属性或学习任务时，优先使用相近的分组、名称和顺序，减少读者反复寻找同类信息的成本；不把所有结构一致性都当成模板僵化。框架先解释共同关系，再为各对象保留必要差异。

共同框架可以在知识类型范围内成为 B 共识，但不推广成所有学科的目录。缺乏实际学习需要的栏目不填满；特殊性质、课程范围和依赖关系允许增减或调序。公式推导、算例可紧随相应性质，不为栏目统一移到远处。框架用于承载内容，不构成纳入新内容的依据。

## 最小充分重构

知识点文档不是课件缩写。原材料篇幅不决定输出篇幅；保留能够独立理解、逻辑重建、考试调用和快速复习所需的最少充分信息。

判断一项内容是否需要保留，依据它是否承担以下实际作用：

- 直接支持已确认的考核动作；
- 是后续知识的必要前置；
- 缺失会造成高概率错误；
- 删除后无法独立重建关键结论；
- 是教师明确编号、命名或反复强调的检索锚点。

满足保留依据不自动意味着详细展开。再结合本章真实任务、读者理解障碍、错误风险和后续依赖，选择简述、必要步骤或完整解释；不能仅因“考过、教师编号、样稿详写”就扩展全部证明与变体。推导保留使读者理解关键一步并完成所需操作的充分链条，不机械要求每个公式证明；必要条件始终随相关内容保留。

教师显性编号项即使共享机制，也先保留独立定位，再合并解释共同机制。

## 目标读者与首次学习

默认面向具备中国普通高中毕业生一般学习基础、首次学习本课程的读者。课程材料明确的先修要求及用户说明按其适用范围调整这一默认起点。从读者熟悉的知识或前文已经讲清的内容起讲，遇到超出起点的前置知识，就地补足理解当前任务所需的一步。

先让读者辨认问题与对象，走通关键关系和首次调用，再展开不影响首次调用的复杂变体、技术证明与形式边界。可推迟或折叠这些细节，但改变适用性、推导正确性或答案的条件仍须就地保留。定义过术语和符号不等于已经能操作。

首次使用新方法需要演示时，用最小完整例子从已知条件走到方法选择、关键操作和结果解释。比较易混的概念或方法时，适合共用对象、数据或情境的，优先复用同一例子，说明两者各自回答什么问题。已有说明足以理解和使用时即可收束。

## 轻量覆盖核对

固定格式：`来源定位｜覆盖项｜标记｜去向`。

- `覆盖项`：仅名词、公式名、定理编号或短语；
- `标记`：`T` 教师显性、`E` 考核、`D` 后续依赖、`R` 高风险，可组合；
- `去向`：`KEEP`、`MERGE:id`、`REF:path`、`MOVE:file`、`OMIT`；
- 禁止写定义、机制、理由、摘要或完整句；
- `OMIT` 必须能在工作记录中说明理由，但不把理由塞进表格。

核对表是校验清单，不是第二份草稿；默认不长期保存。

## 保留后的逻辑归属

保留依据和正文位置分别判断。对可能造成跳跃的内容，先确认它延续哪个问题、继承哪条关系、改变哪个条件或解决哪个新应用：

- 主干与必要前置按问题和依赖组织，理解所需的连接句属于必要信息；
- 条件变体说明保留什么、改变什么，以及哪条关系和结论随之变化；
- 更换研究对象或问题的应用独立设入口，不伪装成原主线的连续推导；同一对象下具有独立复习、再次调用价值的完整应用，也应有标题、锚点等明确入口并能关联所用方法。面向目录检索的笔记应能从目录找到它，不能只用正文粗体代替。短代入例或只解释一步的例子保持就地；入口形式和标题层级服从调用关系与有效课程配置，不把每个算例提成同级标题；
- 能自然衔接的内容合并解释；无法说明必要性或联系的补充重新取舍或调整位置。

这些角色用于内部决策，不要求每章配齐或逐段标记。覆盖去向不能替代逻辑归属；通常在内存中判断，复杂连接才在代理工作区记录短语级依赖，不增加第二套覆盖表。

## 微结构触发

概念、公式、模型、比较、政策和案例的候选字段用于检查实际学习需要，不直接转换成成品目录。先判断相关说明本身是否需要保留：缺失会影响下列任一事项时进入正文：

- 独立理解及必要的学习衔接；
- 概念判断；
- 方法或模型选择；
- 推理恢复；
- 考试答案。

内容保留后，再按“板块内部的内容属性与标识”判断如何显露结构。标题或标签本身的理解、区分和检索价值可以构成呈现理由，不要求删去标签后答案发生变化；也不能因想配齐栏目而新增无实际学习需要的内容。图形角色按下节决定；布局、配套文字和逐图验收执行呈现规则。不能用“文字能说清”取消需要学习或调用的图形。

## 图形角色与训练依据

在具体知识单元判断图形角色，不为整门课或整章固定模式：

- 图形主导：图形承载模型表示、建模、推理或操作，本身属于需掌握的知识。将图与文字共同组织，不能等文字解释失败才配图。
- 文字/数学主导、图形辅助：图帮助理解形状、区域、阈值或关系，按具体额外价值选用；已有表达充分且图仅重复时省略。
- 同一板块可以混合：形态比较借助图，存在条件和数值结论依赖定义、推导或计算。不能凭有限范围示意图证明一般数学结论。

优先从本章适用训练中识别建图、读图、曲线移动、区域判断及依赖几何关系的求解动作。结合有效 O 的用途内重要程度、任务核心性与频率判断；高频是强支持，但不设次数门槛，明确的核心任务即使仅一次也应支持。题目未写“画图”不代表推理不用图，题内有图也不自动证明图是考查核心。

没有明确训练证据时，仍可依据独立理解和后续依赖判定必要性，注明推断，不虚构高频或考试要求。区分图的教学必要性与考核必要性，不把所有学习目标缩为考试。

图形主导单元按需建立“对象与条件 → 图中关系及其依据 → 变化/推理 → 结论与使用边界”。这不强制图先于文字，也不要求所有图配同样字段。具体配套说明、布局和验收统一见 [presentation-rules.md](presentation-rules.md#图文组织)。

## 板块内部的内容属性与标识

保留内容后，按其共同属性或讲解功能形成解释单元，区分定义、条件、推导、机制、应用等实际任务。先确定组段归属与连续关系，再按 [标题与解释单元](presentation-rules.md#标题) 选择低一级标题、短标签或直接接续正文；不先写成长段再机械插标题。

一个解释单元可包含多段文字、公式和图；切换解释功能且读者难以辨认时须显露结构。符号、条件仍紧邻使用处，连续推导不逐行切碎，不能为集中成栏移走必要信息。

## 段落功能测试

每段至少承担一种功能：定义、机制、方法、因果/推理、必要的上下文连接、会改变结论的边界或知识调用。还需能解释它为何出现在当前位置。删除后不影响这些功能的句段应删除或合并；不能因连接句不新增知识，就删掉恢复推理或条件切换所需的桥梁。

信息有用不等于组织清楚。段内应能辨认当前问题以及条件、操作、结果与解释的关系，不强制写成四栏模板。切换到另一计算目标或研究任务时，补必要连接或另起段落，不用连续分号把多个任务压成一段；连续推导中的必要解释保持衔接。

再检查同一标题所辖组段是否共同回答一个明确问题，以及递进、平行、对比关系是否清楚。对象、冲击/条件类型、方法选择或独立调用任务转换时，判断是否需要新的知识入口；同一知识的解释属性转换按上节选择标识。段落提供理解停顿，标题和标签区分主题或属性；不把每次换段都升级为小节，不以段落数量、字数或句长决定拆合。具体措辞与语气按 [presentation-rules.md](presentation-rules.md#语言) 审读。

## 压缩后回归

完成取舍后重新确认能否脱离原材料恢复：

- 模块核心问题；
- 必要前置；
- 关键推理链；
- 符号所量的对象、必要口径与公式条件；
- 承担机制解释的最小案例；
- 会改变答案的边界；
- 教师显性检索锚点。

先只读标题树，检查核心问题、必要比较和独立调用是否可定位；再结合局部标签与正文，检查板块内需要区分或查阅的内容属性是否清楚，以及组段归属、必要前置、条件或研究问题的转换及分支与主线的连接。不能因目录增加层级就判定组织已清楚。图形验收按呈现规则执行。

从本章课件或训练实际给出的信息出发，按目标读者的前置，仅凭笔记完成一次代表性的计算、解释或判断。任务直接给出的量可以使用。对需要自行得到的中间量或判断，实际检验读者能否依据正文取得它、说明关键一步为何成立，再选用方法、解释结果并核查适用条件。记录实际验证范围，读者的学习效果须由真实反馈判断。

缺失时只补回必要信息，不恢复一般背景或重复案例。用真实反馈中的代表性问题检验符号、推导、条件和阅读路径；追问是理解障碍的证据，不自动证明正文错误，也不要求把所有问答写进正文。

## 信息所有权

本 Skill 只拥有正式知识点正文的生成权。知识点文件内部及模块之间，每项完整解释选择一个主归属，其他位置只保留必要的短引用或链接，避免重复。

现有课程流程中的术语表、练习、作业、错题、复习提纲和题型材料属于外部阶段或外部文档。需要说明接口时可以只读引用，但不得由本 Skill 创建、重组、复制完整解释或改变其职责。
